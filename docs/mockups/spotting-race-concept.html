Rarity Color Key

  • Very Common — 0 pts
  • Common — +1 pt
  • Uncommon — +2 pts
  • Rare — +4 pts
  • Very Rare — +7 pts

Tile States

  • Green tint — you claimed it
  • Yellow tint — opponent claimed it (fades out, new tile queues in)
  • Red expiry bar — tile about to rotate out
  • Orange expiry bar — 25% time left (warning)
  • Claim denied flash — red border pulse if both tap at once

Rolling Window Logic

Tiles age off oldest-first. When a tile is claimed or expires, a new one slides into its slot immediately. Six slots are always populated (or fewer if pool is small).
