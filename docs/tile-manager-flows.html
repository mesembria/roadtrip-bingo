Design Notes
DESCRIPTION = PROMPT
The description field serves double duty — stored in squares.json and used verbatim as the image generation prompt (with the style constant appended). No separate prompt editor.
IMAGE GATING
Create Tile is blocked while generation is in flight or a result is pending. Must resolve (approve or discard) before saving. Prevents saving a tile with an ambiguous image state.
NO EMOJI FIELD
Emoji removed per feedback. If the existing JSON has emoji values they're preserved on edit — just not shown as a form field in the new-tile flow.
