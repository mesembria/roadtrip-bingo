# Exit Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an exit button to `GameView` and `SpottingRaceView` that lets any player leave mid-game, with a confirm dialog tailored to their role (solo / joiner / host), and a graceful "host ended the game" alert pushed to peers when the host exits.

**Architecture:** A new `.hostLeft` network message is added to `MultipeerMessage`. `AppState` gains `exitGame()` (broadcasts `.hostLeft` if host, then calls `goHome()`) and a `@Published var gameEndedByHost` flag set when a peer receives the message. A small `✕` button in the top-right of the game grid area triggers a role-specific confirm alert; a separate `gameEndedByHost` alert is attached to `GameView`, `SpottingRaceView`, `WinView`, and `PlayAgainView` so peers see it regardless of which screen they're on when the host exits.

**Tech Stack:** Swift 5.9, SwiftUI, MultipeerConnectivity, XCTest

        Button { showExitConfirm = true } label: {
